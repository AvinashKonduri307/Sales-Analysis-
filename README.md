# Pizza Sales Dashboard using Power BI

The Pizza Sales Dashboard is an interactive business intelligence project developed using Power BI to analyze and visualize pizza sales performance data. The primary objective of this project is to transform raw sales data into meaningful insights that support business decision-making and improve overall sales analysis.

This dashboard provides a comprehensive overview of key business metrics, including total revenue, total orders, average order value, total pizzas sold, and sales trends across different time periods. Various visualizations such as bar charts, line graphs, KPI cards, and pie charts were used to present data in a clear and user-friendly manner.

The project includes detailed analysis of pizza categories, pizza sizes, top-selling products, and sales performance by weekdays and months. Through data visualization, the dashboard identifies customer purchasing patterns, peak business days, and the most profitable pizza categories. Insights such as higher weekend sales, maximum revenue-generating pizza types, and the contribution of large-sized pizzas to total sales help businesses better understand customer behavior and optimize operations.

Data cleaning and transformation processes were performed using Power Query to ensure accurate and structured reporting. DAX (Data Analysis Expressions) functions were implemented to create calculated measures, KPIs, and dynamic metrics for deeper business analysis. The dashboard also features interactive filters and slicers, enabling users to explore data efficiently and customize reports based on their requirements.

Technologies and tools used in this project include Power BI, Power Query, DAX, data modeling, and data visualization techniques. This project enhanced analytical thinking, dashboard design skills, and the ability to derive actionable insights from business data.

The Pizza Sales Dashboard demonstrates practical knowledge of business intelligence and data analytics by converting complex sales data into visually appealing and easy-to-understand reports. This project showcases the ability to work with real-world datasets, perform sales analysis, and create professional dashboards that support data-driven business decisions.
